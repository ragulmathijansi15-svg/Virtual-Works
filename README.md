# UI/UX Design Portfolio

A professional five-project UI/UX portfolio covering website redesign, mobile product interface design, website wireframing, UX case-study analysis, and SaaS landing-page strategy.

## Executive overview

| Task | Project | Focus | Deliverables |
|---|---|---|---|
| [Task 1 — Website UI Redesign](./task1-website-ui-redesign/) | Northstar Home Services | Modernize an outdated local-services website for clarity, trust, and conversion | Before/after analysis, responsive UX plan, design specification |
| [Task 2 — Mobile App Interface](./task2-mobile-app-interface/) | Momentum | Create a focused task-management experience for realistic daily planning | User flow, screen layouts, mobile component guide, design tokens |
| [Task 3 — Website Wireframing](./task3-website-wireframing/) | Northstar Studio | Plan a four-page consultancy website before visual styling | Low/mid-fi wireframes, navigation schema, layout specification |
| [Task 4 — UX Case Study](./task4-ux-case-study/) | PantryPal | Evaluate and improve a meal-planning product flow | Research findings, pain points, UX solutions, validation metrics |
| [Task 5 — Landing Page Design](./task5-landing-page-design/) | Relay | Build a high-converting desktop SaaS landing page | Value proposition, hierarchy, CTA strategy, section specifications |

## Portfolio strengths

- **Strategy:** each project begins with a clear problem, audience, opportunity, and success signal.
- **UX structure:** user flows, information architecture, page hierarchy, and recovery paths are documented before decoration.
- **UI systems:** typography, color, spacing, grids, components, states, and accessibility requirements are specified for handoff.
- **Responsive thinking:** desktop, tablet, and mobile behavior are defined rather than treated as afterthoughts.
- **Evidence-aware communication:** assumptions and expected impact are explicitly separated from measured results.
- **Figma-ready documentation:** every project includes a clear canvas organization and Auto Layout guidance.

These are professional design specifications and portfolio case studies. Where research or launch data is not available, findings are labeled as assumptions, hypotheses, targets, or expected impact rather than presented as measured results.
